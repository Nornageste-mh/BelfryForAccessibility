## 一、这个东西是什么

一个让**读屏软件用户**能玩《钟塔》的补丁。装上之后：

- 没有配音的剧情文本会被读屏念出来（旁白、主角内心、无配音配角）
- 有配音的台词**不念**，只放游戏语音 —— 避免读屏和语音叠在一起
- 选项会被一次念完，然后按数字键 `1`-`9` 选
- 手机聊天消息会被念出来
- 标题菜单 / 存读档 / 设置 / 画廊可以用键盘操作并被朗读

它**不修改任何游戏文件**：补丁由 BepInEx 在游戏启动时挂载到内存里。
所以安装 = 拷文件，卸载 = 删文件。

## 二、安装

### 1. 找到游戏根目录

在 Steam 里右键《钟塔》→ 管理 → 浏览本地文件。
你会看到一个有 **`The Belfry.exe`** 的文件夹，这就是游戏根目录。

### 2. 把补丁拷进去

把这个压缩包解压后的**所有东西**（`BepInEx\` 文件夹、`winhttp.dll`、
`doorstop_config.ini`、`.doorstop_version`、`nvdaControllerClient.dll`、
`licenses\`）**整体**复制到游戏根目录，保持目录结构不变。

复制完游戏根目录应该长这样：

```
The Belfry.exe
UnityPlayer.dll
winhttp.dll                ← 新增
doorstop_config.ini        ← 新增
.doorstop_version          ← 新增
nvdaControllerClient.dll   ← 新增
BepInEx\                   ← 新增
  core\        （16 个文件）
  plugins\
    BelfryA11y.dll         ← 补丁本体
    nvdaControllerClient.dll
licenses\                    ← 第三方许可证，别删
The Belfry_Data\
```

### 3. 启动游戏

正常从 Steam 启动即可。启动几秒后应该能听到一句
「钟塔无障碍补丁已加载」。

听不到就去看 `BepInEx\LogOutput.log`，以及本文第五节的故障排查。

## 四、配置

第一次运行后会生成配置文件：

```
游戏根目录\BepInEx\config\belfry.a11y.reader.cfg
```

用记事本打开就能改。**改完要重启游戏。**
文件里每一项上面都有中文说明，这里只列几个最常改的：

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `朗读无配音剧情` | `true` | 关掉就只剩有配音的台词 |
| `朗读时带上说话人` | `true` | 关掉只念台词，不念「许堇：」 |
| `重读按键` | `Backspace` | 填 KeyCode 名，例如 `Tab`、`F1`、`Home` |
| `菜单键盘导航` | `true` | 关掉就完全恢复游戏原本的鼠标操作 |
| `启动时播报` | `true` | 关掉那句「无障碍补丁已加载」 |
| `语音后端` | `自动` | 依次试 Tolk → NVDA → SAPI |

## 五、故障排查

### 完全没有声音

1. 先确认 `BepInEx\LogOutput.log` 里有 `Loading [The Belfry A11y Reader ...]`
   - 没有 → BepInEx 没挂上。检查 `winhttp.dll` 和 `BepInEx\core\` 是不是
     在游戏根目录
2. 看日志里这一行：`语音后端就绪: xxx`
   - `无` → 三个后端都没起来，往下看
   - `NVDA` → 需要 NVDA 正在运行
   - `SAPI` → 用的是 Windows 内置语音，**中文需要装中文语音包**，
     否则会用英文语音念中文（听不清但能说明通路是通的）
   - `Tolk` → 最好的一档，能自动适配多种读屏
3. 想确认是哪一环坏了，把配置里的 `语音后端` 钉死成 `SAPI` 再看日志

### 能听到提示，但剧情不念

- 检查配置 `朗读无配音剧情` 是不是被改成 `false` 了
- 有配音的台词本来就不念（这是设计）—— 试试按 `Backspace` 重读

### 菜单里方向键乱跳 / 找不到某个按钮

- 把配置 `界面诊断日志` 改成 `true`，重启游戏，进入导航模式，
  然后看 `LogOutput.log`：里面会列出扫到的每一项和**被排除的控件及原因**
- 排查完记得改回 `false`，否则日志会很大

### 游戏更新后补丁失效

补丁是按游戏内方法名挂的，游戏大更新后会失效。
到仓库提 issue，或等更新。

## 六、卸载

删掉游戏根目录下的 `winhttp.dll`，补丁立刻完全失效（游戏恢复正常）。

想彻底清理，再把 `BepInEx\`、`doorstop_config.ini`、`.doorstop_version`、
`nvdaControllerClient.dll` 一并删掉。

**存档不受影响**，在 `%USERPROFILE%\AppData\LocalLow\Kawayi Play\The Belfry\`。

---

## 七、关于 `licenses\`

补丁里带了第三方组件（BepInEx、UnityDoorstop、HarmonyX、Mono.Cecil、
MonoMod、NVDA Controller Client），它们的许可证要求随二进制一起分发。
**请不要删除这个文件夹。**
