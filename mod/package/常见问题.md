# 常见问题

## 装完之后完全没声音

按顺序查三件事：

**一、补丁加载了没有？**
打开 `游戏根目录\BepInEx\LogOutput.log`，搜 `The Belfry A11y Reader`。
应该能看到这样一行：

```
[Info   :BepInEx] Loading [The Belfry A11y Reader 0.1.0.0]
```

看不到 → BepInEx 根本没挂上。检查这三样是不是都在**游戏根目录**
（有 `The Belfry.exe` 的那一层）：

- `winhttp.dll`
- `doorstop_config.ini`
- `BepInEx\core\`（16 个文件，一个都不能少）

**二、语音后端起来了没有？**

在同一个日志里搜 `语音后端就绪`：

| 日志内容 | 含义 | 怎么办 |
| --- | --- | --- |
| `语音后端就绪: NVDA` | 用的是 NVDA | 确认 NVDA 正在运行；不行就把配置 `语音后端` 改成 `SAPI` 试试 |
| `语音后端就绪: SAPI` | 用的是 Windows 内置语音 | **中文需要装中文语音包**，否则会用英文语音念中文 |
| `语音后端就绪: Tolk` | 最好的一档 | 一般不会有问题 |
| `语音后端就绪: 无` 或没有这一行 | 三个后端全没起来 | 看下一行 `语音不可用: ___`，那里写了每个后端各自失败的原因 |

**三、想确认到底哪一环坏了**，把配置文件里的 `语音后端` 从 `自动`
改成 `SAPI`（钉死系统语音），重启游戏。
SAPI 出声 = 补丁是好的，问题在 NVDA/Tolk 那条链路。

## 能听到「无障碍补丁已加载」，但剧情不念

- 先确认配置 `朗读无配音剧情` 是 `true`
- **有配音的台词本来就不念**（这是设计，避免读屏和语音打架）。
  本作 3812 行里有 1491 行有配音，占 39%。遇到有配音的行听不到朗读是正常的
- 试试按 `Backspace` 重读当前句
- 如果**连续好几行**都没念，把配置 `界面诊断日志` 改成 `true`，
  重启游戏跑一段，然后看日志里有没有 `[朗读]` 行：
  - 有 `[朗读]` 行但没声音 → 语音后端的问题
  - 没有 `[朗读]` 行 → 补丁没接到这一行，请把日志发回来

## 标题菜单里方向键乱跳 / 找不到某个按钮

标题画面原本是一个**旋转环形菜单**，上下键是在「转」它。
补丁在导航模式下（`Tab`）会把它换成位置固定的线性列表。

如果你**没有**按 `Tab` 就用方向键，那走的是游戏原版逻辑，会转菜单 —— 这是正常的。

在导航模式下觉得列表不对，把配置 `界面诊断日志` 改成 `true`，重启，
进一次导航模式，然后看日志：里面会列出扫到的每一项，以及**被排除的控件和原因**。

排查完记得改回 `false`，否则日志会很大。

## 按空格会一次推进两行 / 按回车会把按钮点两下

这是按键归属出问题，属于 bug。请反馈，并附上：

- 当时的 `LogOutput.log`
- 你按的是哪个键、在哪个界面

补丁里已经有两道针对性的防护（`KeyEdge` 的按下闩锁、
`GameFlowManager.HandleAdvanceInput` 与 `StandaloneInputModule` 的提交拦截），
正常不应该发生。

## 社交链接（Steam / 小黑盒 / Bilibili）能不能从菜单里去掉？

已经是默认去掉了。配置项是 `排除的对象名`，默认值 `Attention`
（那一条链接栏在 Unity 里的对象名）。

想让它们回来就把这项清空。

---

## 游戏更新后补丁失效了

补丁是按游戏内方法名挂的，游戏大更新换了方法名就会失效。
表现是：游戏能正常玩，但什么也不念，日志里出现
`Failed to patch ...` 或 `Harmony 补丁失败`。

到仓库提 issue，附上日志。
想临时恢复原版：删掉游戏根目录的 `winhttp.dll` 即可。

---

## 怎么彻底卸载？

删掉游戏根目录下的这些：

```
winhttp.dll
doorstop_config.ini
.doorstop_version
nvdaControllerClient.dll
BepInEx\           （整个文件夹）
```

**存档不受影响**，在 `%USERPROFILE%\AppData\LocalLow\Kawayi Play\The Belfry\`。

---

## 这个补丁会改我的游戏文件吗？

不会。它靠 BepInEx 在游戏启动时把代码挂进内存，磁盘上的游戏文件
一个字节都不动。所以安装和卸载都只是拷/删文件。
